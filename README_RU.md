# Магазин электроники в браузере

Python 3.11+, Flask, SQLite, HTML и CSS.

## Получить исходники

```bash
git clone --branch sqlite-web https://github.com/Se7JoPa/Shop_electro.git
cd Shop_electro
```

Можно также выбрать нужную ветку на GitHub и нажать Code → Download ZIP,
затем распаковать файлы в обычную папку.

## Установка и запуск

Нужен Python 3.11 или новее. Откройте терминал в папке исходников.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

В Windows можно открыть start_windows.bat, в macOS - start_mac.command.
Первый запуск устанавливает зависимости и требует интернет.
Если .command не открывается на Mac, используйте команды терминала выше.

Магазин откроется в браузере: http://127.0.0.1:8000.
Терминал должен оставаться открытым. Для остановки нажмите Ctrl+C.
Если порт занят, запустите run.py --port 8001 интерпретатором из .venv.
Флаг --no-browser отключает автоматическое открытие вкладки.
Адрес работает на том компьютере, где запущен сервер.

База data/shop.sqlite3 создаётся автоматически. При первом запуске
программа предложит задать имя, логин и пароль администратора.
Логин: 3-50 латинских букв, цифр или знаков _. Пароль: 8-128 символов.
Последующая регистрация создаёт покупателей. Общего готового пароля нет.
SQLite входит в Python; отдельный сервер БД не требуется.

## Возможности

- Авторизация и регистрация, роли покупателя и администратора.
- Просмотр товаров, описаний и характеристик.
- Поиск и совместные фильтры по категории, бренду, цене и наличию.
- Добавление, редактирование и удаление товаров администратором.
- Выбор цвета интерфейса с сохранением для каждого пользователя.

## Структура базы

Пять таблиц: users, categories, brands, products, product_specs.
SQL находится в schema.sql, диаграмма в docs/ER_diagram.pdf.
Характеристики удаляются вместе с товаром. Категории и бренды можно
дополнять через редактор базы.

## Данные и резервная копия

Все товары, аккаунты и настройки находятся в data/shop.sqlite3.
Для резервной копии остановите программу и скопируйте этот файл.
Чтобы перенести данные между настольной и браузерной SQLite-версиями,
остановите обе программы и скопируйте shop.sqlite3 в папку data другой версии.
При замене существующей базы сначала сохраните её копию.

Цена хранится целым числом копеек, в интерфейсе показаны рубли.
Внешние ключи включены в каждом подключении. После повторного запуска
изменения сохраняются, удалённые примеры не восстанавливаются.
SQLITE_PATH может задать другой путь к базе как переменная окружения.
Относительный путь считается от папки проекта. .env не используется.
Данные PostgreSQL автоматически не переносятся.

## Сервер и интерфейс

Права проверяются сервером. Пароли хешируются с солью, изменяющие формы
используют CSRF-токены, SQL-запросы принимают параметры.
Сервер слушает только 127.0.0.1 и работает без отладчика.
Изображения обозначают категории товаров.
В разделе «Оформление» можно сохранить свой цвет интерфейса.
Для изменения сортировки и фильтров выберите условия и нажмите «Найти».

## Вертикальный интерфейс

В каталоге появились кнопки «Сетка» и «Вертикально».
Вертикальный вариант открывает узкую страницу с одной карточкой в строке,
как в мобильном приложении, в том числе на широком экране компьютера.
Фильтры сворачиваются над каталогом. Поиск, сортировка, добавление,
редактирование и цвет интерфейса доступны в обоих вариантах.
Выбранный вид сохраняется в этом браузере при переходах и повторном входе.

Чтобы сразу открыть вертикальный вариант:

- Windows: `start_vertical_windows.bat`.
- macOS: `start_vertical_mac.command`.
- В терминале из виртуального окружения: `python run.py --vertical`.

Также можно открыть `http://127.0.0.1:8000/?view=vertical` после запуска сервера.
Кнопка «Сетка» возвращает прежний интерфейс. Оба вида используют одну базу данных.

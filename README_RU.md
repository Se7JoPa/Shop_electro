# Магазин электроники в браузере

Python 3.11+, Flask, SQLite, HTML и CSS.

## Получить исходники

```bash
git clone --branch sqlite-web-payment https://github.com/Se7JoPa/Shop_electro.git
cd Shop_electro
```

Можно также выбрать нужную ветку на GitHub и нажать Code → Download ZIP,
затем распаковать файлы в обычную папку.

## Установка и запуск

Нужен Python 3.11 или новее. Откройте терминал в папке исходников.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

В Windows можно открыть start_windows.bat, в macOS - start_mac.command.
Первый запуск устанавливает зависимости и требует интернет.

Магазин откроется в браузере: http://127.0.0.1:8000.
Терминал должен оставаться открытым. Для остановки нажмите Ctrl+C.
База data/shop.sqlite3 создаётся автоматически. При первом запуске
программа предложит задать имя, логин и пароль администратора.

## Возможности

- Авторизация и регистрация, роли покупателя и администратора.
- Каталог товаров, описания и характеристики.
- Поиск и фильтры по категории, бренду, цене и наличию.
- Добавление, редактирование и удаление товаров администратором.
- Выбор цвета интерфейса.
- Раздел «Оплата» с демонстрационной банковской картой, проверкой полей,
  интерактивным предпросмотром и экраном успешного учебного платежа.

## Важно о демонстрационной оплате

Оплата не подключена к банку и не списывает деньги. Поля карты существуют
только в браузере: форма не отправляет номер карты, срок действия или CVV
на сервер, не записывает их в SQLite, localStorage или журналы. Используйте
только вымышленные данные. Это интерфейсный макет для учебной демонстрации,
а не платёжный инструмент.

## Структура базы и безопасность

Пять исходных таблиц: users, categories, brands, products, product_specs.
SQL находится в schema.sql, диаграмма в docs/ER_diagram.pdf.
Права проверяются сервером. Пароли хешируются с солью, формы используют
CSRF-токены, SQL-запросы принимают параметры. Сервер слушает 127.0.0.1.

## Вертикальный интерфейс

В каталоге доступны варианты «Сетка» и «Вертикально».
Чтобы открыть вертикальный вариант: `python run.py --vertical`.
Также можно открыть `http://127.0.0.1:8000/?view=vertical`.

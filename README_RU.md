# Магазин электроники · SQLite

Python 3.11+, PySide6, SQLite.

## Получить исходники

```bash
git clone --branch sqlite-desktop https://github.com/Se7JoPa/Shop_electro.git
cd Shop_electro
```

Можно также выбрать нужную ветку на GitHub и нажать Code → Download ZIP,
затем распаковать файлы в обычную папку.

## Установка и запуск

Нужен Python 3.11 или новее. Откройте терминал в папке исходников.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

База data/shop.sqlite3 создаётся автоматически. При первом запуске
программа предложит задать имя, логин и пароль администратора.
Логин: 3-50 латинских букв, цифр или знаков _. Пароль: 8-128 символов.
Последующая регистрация создаёт покупателей. Общего готового пароля нет.
SQLite входит в Python; отдельный сервер БД не требуется.

## Возможности

- Авторизация и регистрация, роли покупателя и администратора.
- Просмотр товаров, описаний и характеристик.
- Поиск и совместные фильтры по категории, бренду, цене и наличию.
- Добавление, редактирование и удаление товаров администратором.
- Выбор цвета интерфейса с сохранением для каждого пользователя.

## Структура базы

Пять таблиц: users, categories, brands, products, product_specs.
SQL находится в schema.sql, диаграмма в docs/ER_diagram.pdf.
Характеристики удаляются вместе с товаром. Категории и бренды можно
дополнять через редактор базы.

## Данные и резервная копия

Все товары, аккаунты и настройки находятся в data/shop.sqlite3.
Для резервной копии остановите программу и скопируйте этот файл.
Чтобы перенести данные между настольной и браузерной SQLite-версиями,
остановите обе программы и скопируйте shop.sqlite3 в папку data другой версии.
При замене существующей базы сначала сохраните её копию.

Цена хранится целым числом копеек, в интерфейсе показаны рубли.
Внешние ключи включены в каждом подключении. После повторного запуска
изменения сохраняются, удалённые примеры не восстанавливаются.
SQLITE_PATH может задать другой путь к базе как переменная окружения.
Относительный путь считается от папки проекта. .env не используется.
Данные PostgreSQL автоматически не переносятся.

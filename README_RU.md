# Магазин электроники · SQLite

Технологии: Python 3.11+, PySide6, SQLite.

## Запуск

Установите Python 3.11 или новее. Распакуйте ZIP в обычную папку,
например «Документы». Откройте терминал в папке electronics-shop.
Не запускайте программу непосредственно внутри ZIP.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

При первом запуске программа создаст data/shop.sqlite3 с шестью учебными
товарами и предложит создать администратора прямо в окне. Укажите имя,
логин (3-50 латинских букв, цифр или знаков _) и пароль от 8 до 128 символов.
Затем войдите с этими данными. Общего готового пароля нет.
Позднейшая регистрация создаёт покупателей, а не администраторов.

SQLite встроена в Python. Сервер БД, .env и ручной запуск SQL не нужны.
VPS не нужен: программа работает на компьютере с графическим интерфейсом.
Для дополнительного администратора можно локально запустить create_admin.py
тем же интерпретатором. Это требует доступа к файлу базы.

## Функции

- Вход по логину и паролю, регистрация, роли покупателя и администратора.
- Просмотр каталога, описания и характеристик товара.
- Поиск по названию без учёта регистра, включая русский язык.
- Совместные фильтры категории, бренда, цены и наличия.
- Добавление, редактирование и удаление товаров администратором.
- Подтверждение удаления; каскадное удаление характеристик.
- Цвет кнопок и выделения сохраняется отдельно для каждого пользователя.
- Хеши паролей PBKDF2-SHA256 с индивидуальной солью.

Цены и товары демонстрационные. Фото, корзина и оплата не реализованы.
Справочники категорий и брендов можно дополнять в DB Browser for SQLite.

## База и резервная копия

Пять таблиц: users, categories, brands, products, product_specs.
SQL: schema.sql. Диаграмма: docs/ER_diagram.pdf.
Цена в products.price_cents хранится целым числом копеек; в окне показаны рубли.
В каждом соединении включаются внешние ключи: PRAGMA foreign_keys=ON.
Категории и бренды: RESTRICT. Характеристики товара: CASCADE.

Первое создание схемы выполняется транзакцией; PRAGMA user_version=1
предотвращает повторную загрузку примеров. После перезапуска ваши изменения
сохраняются, удалённые примеры не восстанавливаются.
Для резервной копии закройте программу и скопируйте data/shop.sqlite3.
Не удаляйте data, если хотите сохранить аккаунты и товары.

По умолчанию путь к базе считается от папки проекта, а не текущего терминала.
Другой путь можно задать переменной окружения SQLITE_PATH:

```powershell
$env:SQLITE_PATH = "D:\shop-data\shop.sqlite3"
.\.venv\Scripts\python.exe app.py
```

```bash
SQLITE_PATH="$PWD/my-shop.sqlite3" .venv/bin/python app.py
```

Относительное значение SQLITE_PATH считается от папки проекта.
Файл .env не используется. Данные старой PostgreSQL автоматически не переносятся.

В исходном задании указаны MySQL / PostgreSQL. Эта версия использует SQLite
по вашему запросу. Применение SQLite для сдачи согласуйте с преподавателем.

## Git

В ZIP сохранена локальная история .git и добавлен коммит перехода на SQLite.
Перед собственными коммитами настройте имя и почту:

```bash
git config user.name "ВАШЕ_ИМЯ_ИЛИ_НИК"
git config user.email "ВАША_ПОЧТА"
git log --oneline
```

Создайте пустой репозиторий GitHub и замените ВАШ_ЛОГИН:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/electronics-shop.git
git switch sqlite-desktop
git push -u origin sqlite-desktop
```

Для доработок: git add ., затем git commit -m "Describe your change" и git push.
На GitHub проект автоматически не опубликован. Файл БД исключён из Git.
Если распаковщик пропустил .git, выполните git init, git add . и git commit.

## Проверка и демонстрация

Из папки проекта тем же интерпретатором:

```bash
python -m unittest discover -s tests -v
```

Тесты работают в отдельных временных базах и не трогают вашу data/shop.sqlite3.
GUI-тесты используют offscreen-режим. Результаты: docs/VALIDATION.md.

На демонстрации покажите диаграмму, пять таблиц, вход администратора,
создание и редактирование товара, поиск и фильтры, смену цвета и повторный
вход. Покажите покупателя без кнопок управления, удаление товара и git log.
План документа после демонстрации: docs/REPORT_PLAN.md.

## Ошибки и ограничения

Роли проверяются программой. Владелец файла SQLite может редактировать его
сторонним инструментом; файл не зашифрован. Это учебное локальное приложение.
При ручном редактировании включайте внешние ключи.
Если файл недоступен, перенесите проект в «Документы». Если база занята,
закройте её в другом редакторе и повторите действие. Не указывайте чужую
базу в SQLITE_PATH и не перезаписывайте повреждённый файл.

Для пересборки диаграммы отдельно установите reportlab и запустите
python docs/build_diagram.py. ER_FONT_PATH задаёт путь к русскоязычному TTF.
Для обычного запуска программы reportlab не нужен.

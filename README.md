# Магазин электроники

### Браузерная версия · SQLite

**Python 3.11+ / Flask / SQLite / HTML / CSS**

Магазин открывается в браузере. Сервер работает локально, настройки и товары сохраняются в SQLite.


## Возможности

- Авторизация и роли покупателя и администратора.
- Каталог товаров, описания и характеристики.
- Поиск по названию и фильтрация по категории, бренду, цене и наличию.
- Добавление, редактирование и удаление товаров администратором.
- Персональный цвет интерфейса с сохранением в базе.

## Быстрый старт

**Windows:** запустите `start_windows.bat`.

**macOS:** запустите `start_mac.command` или используйте терминал:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

Магазин откроется по адресу `http://127.0.0.1:8000`. При первом запуске создайте администратора. Терминал должен оставаться открытым.

## Вертикальный интерфейс

В каталоге появились кнопки «Сетка» и «Вертикально».
Вертикальный вариант открывает узкую страницу с одной карточкой в строке,
как в мобильном приложении, в том числе на широком экране компьютера.
Фильтры сворачиваются над каталогом. Поиск, сортировка, добавление,
редактирование и цвет интерфейса доступны в обоих вариантах.
Выбранный вид сохраняется в этом браузере при переходах и повторном входе.

Чтобы сразу открыть вертикальный вариант:

- Windows: `start_vertical_windows.bat`.
- macOS: `start_vertical_mac.command`.
- В терминале из виртуального окружения: `python run.py --vertical`.

Также можно открыть `http://127.0.0.1:8000/?view=vertical` после запуска сервера.
Кнопка «Сетка» возвращает прежний интерфейс. Оба вида используют одну базу данных.

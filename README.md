# Магазин электроники

### Браузерная версия · SQLite

**Python 3.11+ / Flask / SQLite / HTML / CSS**

Магазин открывается в браузере. Сервер работает локально, настройки и товары сохраняются в SQLite.


## Возможности

- Авторизация и роли покупателя и администратора.
- Каталог товаров, описания и характеристики.
- Поиск по названию и фильтрация по категории, бренду, цене и наличию.
- Добавление, редактирование и удаление товаров администратором.
- Персональный цвет интерфейса с сохранением в базе.

## Быстрый старт

**Windows:** запустите `start_windows.bat`.

**macOS:** запустите `start_mac.command` или используйте терминал:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

Магазин откроется по адресу `http://127.0.0.1:8000`. При первом запуске создайте администратора. Терминал должен оставаться открытым.

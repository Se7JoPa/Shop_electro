# Магазин электроники

**Три реализации · Python 3.11+ · Русский интерфейс**

Каталог электроники с авторизацией, поиском, фильтрами и управлением товарами.
Одна предметная область реализована как настольное приложение с PostgreSQL,
настольное приложение с SQLite и локальный сайт с SQLite.


## Выберите версию

Каждая реализация находится в отдельной ветке. В `main` размещены обзор и диаграммы.

| Ветка | Интерфейс | База данных | Для чего подходит |
|---|---|---|---|
| **[postgresql](https://github.com/Se7JoPa/Shop_electro/tree/postgresql)** | Окна PySide6 | Сервер PostgreSQL | Настольный каталог с серверной базой |
| **[sqlite-desktop](https://github.com/Se7JoPa/Shop_electro/tree/sqlite-desktop)** | Окна PySide6 | Файл SQLite | Быстрый локальный запуск без сервера БД |
| **[sqlite-web](https://github.com/Se7JoPa/Shop_electro/tree/sqlite-web)** | Браузер, Flask + HTML/CSS | Файл SQLite | Работа с каталогом через веб-интерфейс |

**Как открыть нужную версию на GitHub:** над списком файлов нажмите меню `main`
и выберите ветку из таблицы. В каждой ветке есть свой README, исходники и инструкция.

После клонирования репозитория:

```bash
git switch postgresql
```

или:

```bash
git switch sqlite-desktop
```

или:

```bash
git switch sqlite-web
```

Перед сменой версии остановите программу и сохраните собственные изменения.

## Возможности

- **Авторизация:** логин, пароль и роли покупателя и администратора.
- **Каталог:** категории, производители, описание и характеристики товаров.
- **Поиск и фильтры:** название, категория, бренд, цена и наличие.
- **Управление:** добавление, редактирование и удаление товаров администратором.
- **Оформление:** персональный цвет интерфейса сохраняется для пользователя.
- **Данные:** реляционная схема, ограничения и внешние ключи.

Корзина, оплата и оформление заказов не реализованы.

## Что запускать

| Версия | Точка входа | Дополнительная подготовка |
|---|---|---|
| PostgreSQL | `python app.py` | Создать БД, выполнить SQL, настроить `.env`, запустить `create_admin.py` |
| SQLite, окна | `python app.py` | База и первый администратор создаются через приложение |
| SQLite, браузер | `python run.py` | База и первый администратор создаются через сайт |

Сначала установите зависимости командой `python -m pip install -r requirements.txt`
в виртуальном окружении выбранной версии. Подробные команды для Windows и macOS
находятся в её `README_RU.md`.

В браузерной ветке также есть `start_windows.bat` и `start_mac.command`.
Сайт работает локально: после запуска откройте `http://127.0.0.1:8000`.

## Проектирование базы

Пять сущностей: пользователи, категории, бренды, товары и характеристики.
Категория и производитель связаны с товарами отношением 1:N, товар с характеристиками — 1:N.
Пользователи хранят данные входа, роль и выбранный цвет.

| Документ | Ссылка |
|---|---|
| PostgreSQL: ER-диаграмма | [Открыть PDF](docs/ER_postgresql.pdf) |
| SQLite: ER-диаграмма | [Открыть PDF](docs/ER_sqlite.pdf) |
| SQL для конкретной реализации | `schema.sql` в соответствующей ветке |

SQLite-версии используют одинаковую структуру: файл `data/shop.sqlite3`
можно переносить между настольной и браузерной реализациями после остановки программ.

## Хранение данных

Пароли хешируются с солью. `.env`, файлы SQLite, ключи и виртуальное окружение
не включаются в Git. Роли ограничивают действия в программе; владелец самой БД
может редактировать данные напрямую.


## Развитие проекта

История сохранена: проектирование PostgreSQL → переход на SQLite → браузерная версия.
Ветки показывают самостоятельные варианты одной задачи. Дальнейшие изменения
фиксируйте отдельными коммитами в нужной ветке.

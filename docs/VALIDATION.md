# Проверка браузерной версии

Все 22 автоматические проверки прошли, пропущенных нет.

8 интеграционных проверок SQLite на временных файлах: авторизация,
цвет, CRUD и фильтры, каскад, откат транзакции, права, внешние ключи,
однократная инициализация, сохранение после перезапуска, русский поиск,
точная цена в копейках.

3 проверки PBKDF2: верный и неверный пароль, независимые соли,
безопасный отказ при повреждённом хеше.

11 проверок HTTP через тестовый клиент Flask: первая настройка и запрет
её повторения; вход и выход; регистрация и занятый логин; запрет админских
маршрутов покупателю; CSRF и подтверждение удаления; добавление и изменение
товара, валидация; поиск, фильтры, сортировка и пустые результаты;
цвет и экранирование HTML; заголовки, неизвестные товары и недоверенный Host;
совместимость с прежней SQLite; сохранение ключа сессий после перезапуска.
Каждая проверка работает с настоящим отдельным SQLite-файлом.

Вёрстка каталога, входа и карточки товара визуально проверена в Chrome.
Проверена узкая вёрстка каталога при ширине 390 px. Для этого использованы
статически отрендеренные HTML-страницы из настоящих шаблонов приложения.
Мост предпросмотра не предоставлял Python-среду, поэтому действия браузера
с живым Flask-сервером в этой среде не проверялись. Серверное поведение
проверено тестовым клиентом Flask. Ручную проверку запуска на вашем
Windows/macOS выполните после установки зависимостей.

Компиляция Python и синтаксис bash-скрипта проверены.
В архив не включены тестовые аккаунты, файлы баз, ключи и материалы предпросмотра.
История Git сохранена и дополнена коммитом браузерной версии.
Публикация в интернете и на GitHub не выполнялась.

# Проверка поставки

Проверено при подготовке проекта:

- Три проверки PBKDF2: правильный и неправильный пароль, разные соли,
  безопасный отказ при повреждённом хеше.
- Две проверки интерфейса PySide6 в offscreen-режиме: окно каталога,
  доступность управления только для администратора и отправка формы
  товара с ценой и характеристиками. Для этих проверок использован
  тестовый заменитель БД; они не подтверждают выполнение SQL на сервере.
- Компиляция Python-файлов.
- Синтаксический разбор schema.sql парсером PostgreSQL (pglast).
- Визуальная проверка PDF-диаграммы и окна каталога.

Живой сервер PostgreSQL в среде подготовки отсутствовал. Пять
интеграционных проверок в tests/test_integration.py подготовлены, но
не выполнялись с настоящей БД. Они проверяют вход, права, CRUD и фильтры,
откат транзакции и сохранение цвета. После настройки тестовой базы
нужно запустить их по README_RU.md.

Архив не опубликован на GitHub. Внутри есть локальный Git-репозиторий;
команды подключения своего удалённого репозитория указаны в инструкции.

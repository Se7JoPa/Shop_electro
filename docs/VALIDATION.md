# Проверка SQLite-версии

Все 14 автоматических проверок прошли, пропущенных нет.

Восемь интеграционных проверок используют настоящие временные SQLite-файлы:
вход и неверный пароль; сохранение цвета; CRUD, фильтры и каскад;
откат неудачного обновления; внешние ключи и RESTRICT; запрет действий
покупателю; сохранение данных после повторного открытия и однократная
первичная настройка; русский поиск и точное хранение цены в копейках.

Три проверки паролей: правильный и неправильный пароль, независимые соли,
безопасный отказ при повреждённом хеше.

Три GUI-проверки PySide6 в offscreen-режиме: роли и каталог; форма товара;
первичная настройка администратора, вход и добавление товара через окна
на настоящем SQLite-файле. Сообщение об успешной регистрации в последней
проверке заменено заглушкой, чтобы не блокировать автоматический прогон.

Дополнительно: компиляция Python-файлов, визуальная проверка диаграммы
и окна каталога. Проверки выполнены в Linux; ручная проверка на вашем
Windows/macOS нужна после установки зависимостей.

Старая история Git сохранена; переход на SQLite зафиксирован новым коммитом.
Автоматическая публикация на GitHub и миграция прежних данных не выполнялись.

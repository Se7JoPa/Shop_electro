# План описания курсового проекта

Тема: «Магазин электроники».

Это план документа. Финальное описание оформляется после демонстрации,
как указано в задании. Результаты демонстрации и скриншоты нужно добавить
после фактического запуска на компьютере студента.

1. Введение: цель проекта и задачи из задания.
2. Предметная область: каталог электроники, покупатель и администратор.
3. Выбранные технологии: Python, PySide6, PostgreSQL, Git.
4. Проектирование БД: ER-диаграмма, пять таблиц, типы, PK, FK,
   ограничения CHECK и UNIQUE, каскадное удаление характеристик.
5. Реализация: разделение интерфейса, запросов и работы с паролями.
6. Функции: авторизация, каталог, фильтры, поиск, добавление, удаление,
   редактирование, сохранение цвета. Для каждой приложить свой скриншот.
7. Проверка: успешный вход, неверный пароль, покупатель без кнопок управления,
   поиск без результатов, комбинированные фильтры, добавление и удаление,
   восстановление выбранного цвета после входа.
8. Git: ссылка на свой репозиторий и реальные коммиты доработок.
9. Заключение: что выполнено и возможные улучшения.
10. Источники: официальные руководства Python, Qt for Python, PostgreSQL и Psycopg.

Источники для изучения:
- https://docs.python.org/3/
- https://doc.qt.io/qtforpython-6/
- https://www.postgresql.org/docs/
- https://www.psycopg.org/psycopg3/docs/
